# はじめに

こんにちは❗️Riochinと申します。埼玉在住。普段は、津田塾大学の情報科学科でプログラミングを勉強しています。

2026年7月1日から8月28日までの2ヶ月間、MIXIのエンジニアインターンとして、mixi2の開発チームでフルスタックに働いていました！

mixi2は、2024年12月16日にリリースされた **「今を共有でき、すぐ集える」** をコンセプトにしたソーシャル・ネットワーキング サービス（SNS）です。

https://mixi.social/

そして私は、インターンが始まる前から毎日1時間以上mixi2を開くほどのヘビーユーザーでした。この2ヶ月は、私にとって**大好きなアプリを「使う側」から「つくる側」に回った期間**ということになります！🧡

ちなみに、リリース前のmixi2チームでインターンをしていた方の体験記もあります。当時は社内でも秘密のプロジェクトだったそうで、読んでいて面白かったです。

https://note.com/_kurikin/n/n6785b8f20e21

この方の記事の最後には、「リリース後の盛り上がりの中で開発できるチームが羨ましい」と書かれていました。私が体験したのは、まさにその「リリース後」。リリースから1年半が経ち、アプリを通してユーザーの声が届く中での開発でした！

# 参加までの流れ

## Dive into MIXIとは

私が参加したのは、MIXIの就業型インターンシップ「Dive into MIXI」の2026年夏版です。基本的に通年で募集されていて、2026年10月現在では冬・春季の募集が出ています👇

https://mixigroup-recruit.mixi.co.jp/recruitment-category/internship/14368/

実際の開発チームの一員として、運用中のサービスを開発するインターンです。配属先は、本人の希望と各部署の受け入れ状況を見てマッチングで決まります。期間や勤務日数も相談できます。

## 選考の流れ

選考は、以下の流れで進みます。

**エントリーシート選考 → 人事社員との面接 → 現場社員との面接（複数回）→ 参加決定**

私の場合は、2026年3月の「[技育祭2026 春](https://geek.supporterz.jp/geeksai/2026spring)」で、MIXIの社員の方にmixi2の好きなところを喋り倒したことをきっかけに、選考のご案内をいただきました。

選考で特に印象的だったのは現場面接です。[のちにメンターになる方](https://x.com/Kunodayo_oboete)から「どんな形式でもオッケーなので自己紹介してください！」と言われたので、[お気に入りのLT](https://speakerdeck.com/riochin/you-da-nodan-sheng-ri-sapuraizunisaitowozuo-tutahua)[^1]をしました。

いい意味で面接を受けている感じがしなくて、「ここで働けたら最高だろうな〜」と思った記憶があります。

## 働き方

ということで、7月1日から念願のmixi2チームにジョイン！

7月は週4日、8月は週5日のフルタイムで働きました。リモートもOKと言われていましたが、体調が悪い日以外は毎日出社していました。

mixi2開発チームではアジャイル開発が取り入れられていて、私も社員さんと同じように、朝会やアイデア会、スプリントレビューなど、毎日なにかしらのミーティングに参加させていただきました。

1日の流れはだいたいこんな感じです：

| 時間 | やること |
| --- | --- |
| 10:00 | 出社 |
| 11:00 | チームの朝会（30分） |
| 12:00 | チームの方とランチ🍙 |
| 13:00〜 | 実装 |
| 16:00 | メンターさんと1on1[^2] ☕️（30分） |
| 16:30〜 | 実装 |
| 18:30 | 1日の振り返り |
| 19:00 | 退勤（または飲み会！🍻） |

また、インターン生でも社員さんと変わらないくらい発言の機会がありました。心理的安全性がすごく高くて意見を交わしやすいチームだったので、顔を合わせてミーティングするのが毎日楽しくて仕方がなかったです。（この雰囲気に感動して、[外部でLTもしました](https://speakerdeck.com/riochin/shotaimen-karade-mo-shinriteki-anzensei-no-takai-chimu-o-tsukurou)）

カフェテリアやマッサージルームなど、オフィス環境もすごく整っています。オフィスについては[Suuさんの体験記](https://zenn.dev/mire0726/articles/e8d3655ca3cac5)の紹介がわかりやすいので、ぜひこちらも読んでみてください！

# ゴール設定

私はこれまで、自分の課題を解決するための個人開発と、ハッカソンでのチーム開発をたくさんしてきました。しかし、個人開発はユーザーをかなり狭く絞っているし、ハッカソンの作品は継続開発/運用までたどり着いていませんでした。

なので今回は、mixi2開発チームで **「大好きなプロダクト」で「チーム開発」と「運用」** に挑戦できること自体が、とても大きなモチベーションになっていました。

そのうえで、インターンを始めるにあたって次の6つの目標を立てました。

1. **アイデアから機能実装、バグ対応まで一気通貫でやる**
2. **触ったことのない技術も触る**
3. **MIXIにどんなチームがあるのか知る**
4. **社内にいっぱいコミュニティをつくる**
5. **ロールモデルを見つける**
6. **mixi2をもっと盛り上げる！！！！**

## リリースした機能

### 話題の履歴

![mixi2の投稿画面。テキスト入力欄の上に「話題を追加」ボタンがある](/images/mixi2-subject.png =350x)
*mixi2の投稿画面*

mixi2の投稿には「話題」をつけられるのですが、話題を追加する画面には「おすすめの話題」しか出てきませんでした。一度使った話題をもう一度つけたいときは、いちいち探し直す必要があったわけです。

そこで、使った話題を「履歴」として出せるようにしました。

![mixi2の「話題を追加」画面。おすすめの話題の上に、過去に使った話題が「履歴」として並んでいる](/images/mixi2-subject-history.png =350x)
*一度使った話題が「履歴」に出るように🎉*

インターン1週目からいただいていたプロジェクトで、バックエンドからクライアント、Webの実装まで全部経験させていただきました。だいたい1ヶ月目くらいでリリースすることができました。

インターンシップで、自分の機能が期間内にリリースまで届いたのはこれが初めてでした。小さいチームならではのスピード感に感動した1タスク目でした！

### リンクカードの任意削除

URLを含むポストを投稿するとき、リンクカードを✖️ボタンで消せるようにしました。

実はこれは、私が出したアイデアが、そのまま採用された機能です。

mixi2で個人開発の告知ポストを投稿した際、自分で作った告知画像だけを見てほしいのに、リンクカードが自動で出てきて**消せず**、ユーザーとしてモヤモヤした経験がありました。

![Before：URLを含むポストで、告知画像の横にmixi2のリンクカードが表示されている](/images/mixi2-ogp-before.png =400x)
*Before：リンクカードが告知画像の横に居座る*

そこで、投稿画面からリンクカードを消せるボタンを追加しました。

![投稿作成画面。リンクカードの右上にある✖️ボタンが赤丸で囲まれている](/images/mixi2-subject-histoy-x.png =400x)
*投稿画面で、リンクカードの✖️ボタンを押すと......*

![After：リンクカードを消して、告知画像だけが表示されている](/images/mixi2-ogp-after.png =400x)
*After：告知画像だけに！🎉*

ユーザーとしての要望がそのまま機能になったのは初めてで、地味ながらすごく愛着の湧いている機能です。

一方で、投稿機能まわりは比較的新しい話題機能に比べて複雑で、考慮すべき点が多くありました。既存の設計に沿って実装方針を提案するのには思ったより時間がかかりましたが、これもいい経験になりました。

### リアクション検索

投稿につけられるリアクションを、文字で検索できるようにしました。

![リアクション検索で「すき」と入力し、季節限定・絵文字・日本語などのリアクションが絞り込まれている画面](/images/mixi2-reaction-search.png =350x)
*「すき」で検索すると、関連するリアクションが出現🎉😻*

これはずっとバックログに積まれていた、優先度低めのタスクでした。

でも、リアクションをつけて盛り上がれるのがmixi2の魅力そのものだと思っていたし、調べたところユーザーさんからの要望も多かったので、自分から「**やりたい！！**」と手を挙げ、担当させていただけることになりました。

いざ始めてみると、キーワードをどう持たせるのか、関連語をどれだけ持たせるのか、ローマ字や英語に対応するのか、表示順はどうするのか......などなど、考えることが山盛りで、仕様を決めるのに時間がかかりました。

タスクを始めた時点でインターンは残り2週間しかなかったので、手戻りが出ないように慎重に仕様書と設計書を作り込み、チームメンバーに共有、検索キーワードをマスタデータに反映し、クライアントでの取得、検索UIの実装、QAで出たバグ対応、リリース申請______！！

......と、ここまでなんとか走り抜け、**インターン最終日にぎりぎりリリース**することができました！

レビュー、QA、告知などが間に合うように協力してくださったチームの方々には、本当に本当に頭が上がりません😭😭🙏🙏

![リアクション検索リリースの公式告知ポスト。「たしかに」で検索するとカニのリアクションが見つかる画像に、カニのリアクションがたくさんついている](/images/mixi2-reaction-search-feedback.png =400x)
*公式の告知ポスト。カニ🦀が大人気*

リリースから2ヶ月経った今でも、mixi2で「リアクション 検索」と検索すると、ユーザーさんからの嬉しい反応がたくさん出てきて、そのたびに胸がいっぱいになります。

# ゴールの達成度

## ⭕ アイデアから機能実装、バグ対応まで一気通貫でやる

最終的に、仕様・設計・実装・リリースの全ての工程を経験することができました！🎉

正直、一気通貫でやること自体は、AIのおかげでかなり簡単になったと感じています。実際、実装はClaudeと一緒にどんどん進められました。

よく言われていることでもありますが、「設計の判断を自分で説明できる力」がエンジニアとして今後さらに求められていくんだろうなと感じました。

## ⭕ 触ったことのない技術も触る

Go、Flutter、gRPCは、どれも実務で使うのは初めてでした。

- **Go（サーバー）**
  大規模なリポジトリで、層ごとに分けて機能を実装しました。DBのスキーマやインデックスの設計も担当しています。[Go College](https://zenn.dev/riochin/articles/6b4099bd6cce6d)で学んだアーキテクチャの理解を活かして、スムーズにオンボーディングできました！
- **Flutter（クライアント）**
  完全初見でした。[新卒向けの研修資料](https://speakerdeck.com/mixi_engineers/2024-new-grad-training-flutter)などをみて勉強しながら、画面やテキストフィールドの状態管理、Widgetの共通化、検索ロジックの実装をしました。
- **gRPC**
  protoを通して、Flutterのクライアントとサーバーをつなぐ部分を実装しました。

## ⭕ MIXIにどんなチームがあるのか知る / 社内にいっぱいコミュニティをつくる

「**いろんな人と1on1するぞ！！！**」と決めて臨んだインターンシップでしたが、結果、13人の社員さんと1on1させていただきました（メンターさんがたくさんセッティングしてくださいました。本当にありがとうございます🙇‍♀️）。

ほかにも、インターン生同士のランチ会を3回企画したり、部活（モケイ部）でガンプラを組み立てたり、社員さんと毎週飲み会に行ったり......チームの内外でたくさんの人と関われました！
いろんな部署/職種の話を聞けたことで、働くことへの解像度もかなり上がりました。

## ⭕ ロールモデルを見つける

**メンターさんがロールモデルすぎました！**

設計やコードレビューで垣間見える技術力や経験の高さはもちろんですが、チームでのコミュニケーションやメンターとしてのサポートの姿勢から、「この人と一緒に働くと楽しい」と感じさせてくれる方でした。その姿勢が、チーム全体の風通しもよくしているように感じました。

私はハッカソンに参加するとき、いつも **「ここを一番楽しいチームにする」** と思って臨んでいます。

だからこそ、メンターさんがつくり出す空気に触れて、 **「楽しい」への向き合い方は仕事へのモチベーションに直結するんだ** と確信できました。チームの中での理想の自分像も、また具体的になりました。

## ⭕ mixi2をもっと盛り上げる！！！！

担当した機能の公式告知ポストには、どれも数百以上のリアクションがつきました。たくさんのユーザーさんが反応してくれて、盛り上げられたと思います🎉

そしてもうひとつ。

インターンが始まってわりとすぐ、チームのみなさんに「りおちんが来てくれてよかった」と思ってもらいたい、と考えるようになりました。大好きなmixi2をつくっていて、初日から温かく迎えてくれた人たちだったからこそです。

そのためにも、Slackと対面でのコミュニケーションをなるべく使い分けるようにしたり、アイデアやユーザー要望を出すようにしたり、チーム向けのリアクション管理ダッシュボードを作ったり......。

私にできることを考えて、全力で実践していました。そして最終日、メンターさんやチームの方に **「りおちんが来て、チームが明るくなってたよ」** と言ってもらえたのが、何よりも、たまらなく嬉しかったです。

ユーザーさんだけでなく、チームも少しは盛り上げられたのかなと思うと、感慨深いものがありました。

## これからインターンへ参加したい人へ

ほかのインターン生の話も聞いていて、配属先が違っても共通しているMIXIのインターンのいいところがあると感じました。

- **裁量の大きい環境で開発できる**
  インターン生でも、運用中のサービスの機能を任せてもらえます。
- **プロダクトへの熱量が高い人たちと働ける**
  どの社員さんも、自分の仕事やプロダクト、そしてMIXIという会社自体が大好きなんだなと感じました。
- **社員さんの人柄がいい**
  「MIXIは"人"がいい」とよく言われますが、本当にそうでした。私が関わった社員の方々は、話しかけるとみなさんとても親切に対応してくださいました。
- **出社したくなる環境**
  ランチや社内カフェ、部活など人と関われる場面が多いうえに、マッサージ室やスタンディングデスクなどの設備もそろっています。
- **柔軟に働ける**
  配属先や募集状況によって異なりますが、私の場合はリモート勤務や勤務日数、期間について相談できました。関西や東海地方からほぼフルリモートで働いてるインターンの方もいました。

「技術スタックが合わないかも？」と迷っている人も、心配しなくて大丈夫だと思います。私もFlutterは完全初見でしたが、会社から配布されるコーディングAIやメンターさんのサポートもあり、1ヶ月目には機能をリリースできました。

事業部によって多少カルチャーや働き方は違うと思いますが、人事の方が自分に合いそうな部署にいい感じにマッチングしてくれるので安心です。

少しでも気になった人には、 **絶対におすすめしたいインターン** です！！

最後にはなりますが、**mixi2チームのみなさん、メンターさん、1on1に時間をくださったみなさん、ランチや部活でご一緒したみなさん、インターン生のみなさん、本当にありがとうございました‼️‼️‼️‼️‼️**
